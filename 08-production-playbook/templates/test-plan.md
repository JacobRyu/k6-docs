## 5. 実施手順

```bash
# 1. 環境変数
export BASE_URL=<https://staging.example.com>
export RUN_ID=<git sha>

# 2. スモーク（1 VU / 1 分）
k6 run -e BASE_URL="$BASE_URL" 01-introduction/smoke.js

# 3. 本試験
k6 run -e BASE_URL="$BASE_URL" -e RUN_ID="$RUN_ID" \
  --out json=reports/load-$(date +%Y%m%d-%H%M).json \
  06-results/summary.js

# 4. 結果確認
cat reports/summary.json | jq '.metrics.http_req_duration.values'
```

## 8. 中止条件

以下のいずれかに該当したら即座に停止し、負荷を 0 にする。

- エラー率が `<5%>` を超えた
- p99 が `<3s>` を超えた
- DB 接続数が上限の `<80%>` に達した
- 外部依存でエラーが発生した
- オンコール / 承認者から停止指示

**停止方法**: `<Ctrl-C / CI の cancel / kubectl delete testrun>`
